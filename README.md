# Regulated Day

Osobista aplikacja na Windows do planowania dnia z budżetem czasu i energii: pokazuje plan, chroni odpoczynek i zawczasu
podsuwa decyzję, zanim dzień się przeleje. Interfejs po polsku, motyw „Pokój lo-fi”.

- Reguły: [`docs/specyfikacja.md`](docs/specyfikacja.md), decyzje: [`docs/decyzje.md`](docs/decyzje.md),
  etapy: [`docs/plan.md`](docs/plan.md), stan: [`docs/postep.md`](docs/postep.md).
- Instalator: wydania w [GitHub Releases](https://github.com/Clatir/RegulatedDay/releases) (`Regulated-Day-Setup.exe`
  z sumami SHA-256); aplikacja aktualizuje się sama.
- Budowanie na Windows: `build-windows.cmd` (pobiera przypiętą wersję Node.js do `.tools\`).
